HTML Survival Guide

HTML is the stuff on the page. Everything is a tag. Most tags come in pairs: an opening tag and a closing tag with a slash.

<p>This is a paragraph.</p>

Every page starts with this skeleton:

<html>
<head>
    <style>
        /* your CSS goes here */
    </style>
</head>
<body>
    <!-- the stuff people see goes here -->
</body>
</html>

The tags you actually need:

<h1>Big title</h1>          (h1 is biggest, h6 is smallest)
<p>A paragraph</p>
<a href="https://google.com">A link</a>
<img src="cat.jpg" alt="a cat">   (no closing tag)
<br>                         (line break, no closing tag)
<b>bold</b> <i>italic</i>

<ul>                         (bullet list)
    <li>thing one</li>
    <li>thing two</li>
</ul>

<div>a box to group stuff in</div>
<!-- a comment, the browser ignores this -->

CSS Survival Guide

CSS makes the stuff look different. It goes inside the <style> tag. Pick a tag, then say what to change:

p {
    color: blue;
    font-size: 20px;
}

That means "make every paragraph blue and 20 pixels tall." Don't forget the colon and semicolon.

Want to style just one thing? Give it a class, then use a dot in CSS:

<p class="spicy">Only this one is red.</p>

.spicy {
    color: red;
}

The properties you actually need:

color: red;                  (text color)
background-color: yellow;    (background color)
font-size: 24px;             (text size)
font-family: Arial;          (font)
text-align: center;          (left, center, right)
width: 300px;                (how wide)
padding: 10px;               (space inside the box)
margin: 10px;                (space outside the box)
border: 2px solid black;     (outline)

Colors can be names (red, tomato) or hex codes (#ff0000).

When It Breaks

  • Did you save the file? Did you refresh the browser?
  • Did you close every tag?
  • Did you forget a semicolon or a curly brace in your CSS?
  • Is your spelling right? colour does not work. It's color.
